How to name layers
  • #title on a text layer → the title column
  • #photo on a rectangle or frame → image from a URL
  • #color with a value like #2563EB → fill colour
  • #badge? → shown when the value is yes/true/1, hidden when empty/no/0
  • #user.name → nested JSON values
  • Component properties (text, boolean, variant) fill by their own name, no renaming needed
  • Column names ignore case, spaces and underscores: First Name = #firstname
